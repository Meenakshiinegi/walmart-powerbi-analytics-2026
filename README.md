# 📊 Walmart Sales & Business Intelligence Dashboard

> An interactive Power BI Business Intelligence dashboard designed to analyze Walmart's sales, revenue, profitability, product performance, returns, and regional trends.

---

## 🚀 Project Overview

This project focuses on transforming Walmart's business data into an interactive and visually engaging Business Intelligence dashboard using **Microsoft Power BI**.

The dashboard brings together information from customers, products, transactions, returns, stores, regions, and calendar data to provide a consolidated view of business performance.

It enables users to explore key business metrics, compare performance across different time periods, identify high-performing products and locations, and understand sales and return trends.

---

## 🎯 Project Objectives

The primary objectives of this project are to:

- Analyze overall sales and transaction performance
- Track revenue, profit, and profit margin
- Monitor product returns and return rates
- Compare current-month performance with previous-month performance
- Identify high-performing product brands
- Analyze performance across countries, states, cities, and stores
- Track weekly revenue trends
- Compare actual revenue against targets
- Provide actionable business insights through interactive visualizations

## 🗂️ Data Model

The dashboard uses a relational data model consisting of multiple business tables.

### Main Tables

- **Customers** – Customer demographic and geographic information
- **Products** – Product details, brands, costs, prices, and product attributes
- **Transaction_Data** – Sales transactions, quantities, customers, products, stores, and dates
- **Return_Data** – Product returns, return quantities, dates, and stores
- **Stores** – Store information including location, type, and size
- **Regions** – Sales regions and districts
- **Calendar** – Date, month, quarter, year, and other time attributes
- **Measure** – DAX measures used for dashboard calculations

The data model allows transaction data to be analyzed across different business dimensions such as products, customers, stores, locations, and time.

## 📈 Dashboard Features

### 1. Product Brand Performance

A detailed matrix visual provides brand-level analysis using:

- Total Transactions
- Total Profit
- Profit Margin
- Return Rate

Conditional formatting is used to highlight differences in brand performance and make important patterns easier to identify.

---

### 2. KPI Performance Comparison

The dashboard provides KPI cards for comparing current-month performance with previous-month performance.

Key comparisons include:

- Current Month Transactions vs Previous Month
- Current Month Profit vs Previous Month
- Current Month Returns vs Previous Month
- Revenue vs Target

This helps identify changes in business performance over time.

---

### 3. Geographic Performance Analysis

The dashboard enables geographic analysis across:

**Country → State → City → Store**

Users can filter the dashboard by different countries and analyze sales performance at various geographic levels.

---

### 4. Revenue Trend Analysis

A weekly revenue visualization is used to identify revenue patterns over time.

This helps users understand:

- Revenue fluctuations
- High-performing periods
- Low-performing periods
- Overall sales trends

---

### 5. Revenue vs Target

A gauge visual compares revenue performance against the defined target.

This provides an executive-level view of whether the business is moving toward its expected revenue target.

---

### 6. Interactive Filters & Navigation

The dashboard includes interactive features such as:

- Country filters
- Slicers
- Drill-down functionality
- Interactive visual selections
- Bookmarks
- Dashboard navigation

These features allow users to explore the data from multiple business perspectives.
